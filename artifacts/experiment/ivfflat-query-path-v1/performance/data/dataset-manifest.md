# Performance Dataset Manifest

The performance dataset is generated by `generate_vectors()` in
`contrib/pgvector/bench/run_ivfflat_benchmark.sh` using the host `awk`
implementation.

| File | Rows | Dimensions | Seed | Bytes | SHA256 |
|---|---:|---:|---:|---:|---|
| `items.csv` | 100,000 | 128 | 17 | 141,788,895 | `e98ac9151fce61d6b5396ee64515936db29f45377c2bf4ef84ed7fe5650f265d` |
| `queries.csv` | 200 | 128 | 97 | 283,092 | `a19e117907916c2e1f6af9c8d12070c81742683e70652fe14713b26674f9a82b` |

`queries.csv` is archived here. The 136 MB `items.csv` is omitted from Git and
must be regenerated. A streamed regeneration on the experiment host produced
the same SHA256 for both files, proving that the checked-in generator recreates
the exact measured dataset.

The database table uses `vector(128)` and a Cosine IVFFlat index named
`profile_items_cos_idx` with `lists=1000`.
