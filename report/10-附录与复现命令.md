## 复现顺序

1. 检出 `muzimu217/ivfflat-query-path-optimization` 分支，确认工作树干净。
2. 对 canonical patch 执行 `sha256sum`，再对 OpenTenBase 基线执行 `git apply --check`。
3. 按 `reproduce-smoke.md` 编译 pgvector，运行 `ivfflat_vector` 回归和 nested-loop rescan；保存计划，确认实际出现多次 IVFFlat loop。
4. 生成固定 item/query 数据，核对 seed、行数、维度、lists/probes 与 manifest；任何字段变化都增加 run id。
5. 交错运行 scalar/vectorized 五次 ABBA，保留每次系统负载快照、动态库哈希和完整 workload 日志。
6. 运行 `python3 report/figures/scripts/01_rescan_memory.py` 到 `04_temp_blocks.py`，再用 `PYTHON_BIN=python3 bash report/build.sh` 生成 PDF；在 `report/build/` 内执行 `shasum -a 256 -c SHA256SUMS`。
