# Figure catalog

All current report figures are generated by the scripts below from the adjacent data snapshots. Each output has an SVG vector file and a PNG preview. The old June figures are outside this directory under `report/appendix/legacy-figures/` and are not used in the main report.

| Figure | Script | Data | Output |
|---|---|---|---|
| Rescan memory | `scripts/01_rescan_memory.py` | `data/rescan_memory.csv` | `output/01_rescan_memory.svg` |
| SIMD pairs | `scripts/02_simd_pairs.py` | `data/simd_matrix.csv` | `output/02_simd_pairs.svg` |
| Perf hotspots | `scripts/03_perf_hotspots.py` | `data/perf_hotspots.csv` | `output/03_perf_hotspots.svg` |
| Temporary blocks | `scripts/04_temp_blocks.py` | `data/query_work_mem.csv` | `output/04_temp_blocks.svg` |

Rebuild all four from the repository root with:

```bash
for script in report/figures/scripts/0*.py; do python3 "$script"; done
```
