# pgvector 查询性能优化需求规格说明书

## 1. 范围

本说明书定义 OpenTenBase 内置 pgvector IVFFlat 查询路径的源码修复、性能验证和可复现交付需求。主结论只覆盖已归档的 `ivfflat-query-path-v1` run；没有把未来的 HNSW 全矩阵或分布式分片研究混入当前验收。

## 2. 目标与非目标

目标是：定位并修复可复现的 rescan 生命周期问题；恢复 OpenTenBase 构建链中已有的自动向量化参数；在固定 Cosine/high-probes workload 上证明性能改善且 recall 不下降；提供回归、原始日志、图表和 PDF。

非目标是：不重写 IVFFlat 算法、不使用手写 SIMD intrinsics、不用降低 recall 换速度、不承诺跨硬件同等收益、不把均匀随机历史图当作主证据。

## 4. 追溯与变更规则

每条通过需求必须能追到源码/命令、原始数据、生成脚本和报告段落。任何改变数据合同、编译器、拓扑或 probes 的实验都创建新 run，不覆盖 `ivfflat-query-path-v1`。延期项不从“待做”改写为“已完成”，除非产生新的验收证据。
