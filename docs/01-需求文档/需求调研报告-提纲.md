## 2. 市场与需求侧（证据点，待你扩写）

- pgvector ≈ 22,600 GitHub stars（2026-08 口径），AWS RDS / Supabase / Neon / Azure 等主流托管 PG 均原生支持——「优化它」的影响面是整个 PG 生态，不是单一产品。
- 向量数据库细分市场：$2.58B（2025）→ $17.91B（2034）（Fortune Business Insights，经 Atlan 转述）；Gartner 口径 CAGR 75.3%；另一口径 $1.73B（2024）→ $10.6B（2032）（Firecrawl）。**两套口径不一致，如实并列并注明。**
- 生产迁移信号：Supabase（原生 pgvector）2025-10 估值 $5B、400 万开发者、30% 新注册为 AI builder；Pinecone→pgvector 成本案例 $675→$250/月、$2,847→$200/月。
- 性能两面性（Tigerdata 对比研究，经 LinkedIn 转述——**成稿时找到并核对一手报告**）：99% recall 下 PG 吞吐约 10× 于 Qdrant，但 P95/P99 尾延迟落后 2×。→ 需求不是"PG 能不能做向量检索"，而是"延迟与召回的平衡能否做好"。

## 3. 竞品与学术对标（引用 R001，成稿时浓缩为你的话）

- AlloyDB（专有 ScaNN）已有 recall 诊断能力；开源 pgvector 无等价物。
- ANN-Benchmarks 方法学（recall-QPS Pareto、10,000 查询）；均匀随机高维向量无效（Beyer et al., ICDT 1999；Rand-Euclidean 反例：HNSW recall 天花板 0.86）。
- HNSW vs IVFFlat：约 30× QPS / 28× p99（Katz/AWS，99% recall）。

## 4. 社区痛点（第一手优先）

- lists/probes 官方只有一句起步建议（rows/1000 或 sqrt(rows)；probes 起点 sqrt(lists)），无引导性工具。
- 「过滤后置」陷阱：ef_search=40 + 10% 选择率谓词 ≈ 只返回 4 条。
- #202 实测遗留：1CN+1DN 拓扑下未触及分布式维度（本项目 W3 补齐）。

## 5. OpenTenBase 特有空白（差异化依据）

- 分布式 ANN：PVLDB Vol.18:1649-1662（Gottesbüren et al. 2025）、SPIRE arXiv:2512.17264、Milvus Discussion #42108（维护者称"数学证明问题"未解）、PgDog 博客（未测 recall）。CN/DN 架构下的分片 recall 行为刻画 = 空白。
